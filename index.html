O que é o localStorage?

Pratique strings, arrays e recuperação dos dados. Recarregue a página ou abra outra aba no mesmo endereço HTTP para observar a persistência.

Use o servidor HTTP indicado no README. O comportamento do localStorage em file:// varia entre navegadores.
